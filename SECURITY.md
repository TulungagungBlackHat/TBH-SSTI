# Security Policy

This tool is for **authorized testing only**: your own systems, labs, CTFs,
contracted assessments, and in-scope bug-bounty targets.

Do not use it for credential theft, phishing, malware, DDoS, defacement,
account takeover, or any unauthorized activity.

## Reporting a vulnerability

Open a GitHub issue with the `[SECURITY]` prefix including:
affected file, reproduction on `127.0.0.1`, expected vs actual behavior.
